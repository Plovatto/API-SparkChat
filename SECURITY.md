# Security policy

## Supported versions

Only the latest version of the `main` branch, which is the published version, receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/Plovatto/API-SparkChat/security/advisories/new).

Do not open public issues for security problems. Include enough detail to reproduce the problem, the affected commit, and the expected impact. Problems that only affect the browser belong in the [web client repository](https://github.com/Plovatto/SparkChat/security/advisories/new).

## Scope

Reports are especially welcome for:

- anything that lets the server, or someone with access to it, read message contents or private keys;
- authentication, session, or device binding bypasses;
- ways to reach other users' rooms, files, or keys;
- server-side request forgery through link previews or media proxies.
