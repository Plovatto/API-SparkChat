# Política de segurança

## Versões suportadas

Só a versão mais recente da branch `main` recebe correções, que é a mesma que está publicada.

## Como reportar uma vulnerabilidade

Se encontrar uma falha de segurança no SparkChat API, **não abra uma issue pública**.

Use o [reporte privado de vulnerabilidades](https://github.com/Plovatto/API-SparkChat/security/advisories/new) do GitHub e conte:

- o que acontece e qual o impacto
- os passos para reproduzir
- a versão ou o commit em que testou

Falhas que permitam acessar mensagens, anexos ou dados de outro usuário, contornar a autenticação ou derrubar o servidor são as mais importantes para mim.

Eu respondo assim que possível e aviso quando a correção for publicada. Se quiser, seu nome entra nos créditos da correção.
