# Política de segurança

## Versões suportadas

Apenas a versão mais recente da branch `main`, que é a versão publicada, recebe correções de segurança.

## Como reportar uma vulnerabilidade

Reporte vulnerabilidades de forma privada pelo [reporte privado de vulnerabilidades](https://github.com/Plovatto/API-SparkChat/security/advisories/new) do GitHub.

Não abra issues públicas para falhas de segurança. Inclua detalhes suficientes para reproduzir o problema, o commit afetado e o impacto esperado.
